# OCTANE network

Wireless communication package for OCTANE rover ground station link.

Provides TCP-based bidirectional communication between the rover and ground station. Encodes rover telemetry (state, faults) for transmission and decodes ground station commands (mode changes).

See also:
- `protocol.md` - TCP frame format, encoding, CRC
- `messages.md` - Message field reference, codes, examples
- `nodes.md` - Node descriptions and topics
